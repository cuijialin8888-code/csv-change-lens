# csv-change-lens

离线比较两份 CSV 数据表。用你指定的样本编号匹配记录，识别新增、删除及修改，
并对明确指定的数值列使用误差容限。默认报告隐藏单元格值和样本编号值，便于放进日志。

[English](README.md) · [完整比较规则](docs/semantics.md) · [安全边界](SECURITY.md)

## 适合什么场景

实验数据重新导出后，确认样本有没有增删、哪些测量值变化、变化是否超过你设定的容限。
“主键”就是用于唯一识别一条记录的列；例如“样本编号 + 重复试验序号”可以共同构成主键。
记录顺序变化不会被误判为数据变化。

## 安装和使用

需要 Python 3.10 或更高版本，支持 Windows、Linux、macOS。在源码目录中安装：

```console
python -m pip install .
```

或者从 [GitHub Releases](https://github.com/cuijialin8888-code/csv-change-lens/releases)
下载 wheel 安装包，然后离线安装：

```console
python -m pip install --no-index --no-deps csv_change_lens-0.1.0-py3-none-any.whl
```

尚未发布到 PyPI。程序运行时没有第三方依赖。

仓库中的 CSV 全部是合成示例，不是真实实验数据：

```console
csv-change-lens examples/before.csv examples/after.csv --key sample_id --key replicate --numeric temperature_c --abs-tol 0.1
```

结果：新增 1 条记录，修改 1 条记录（2 个单元格），2 条记录在所选规则下保持一致。
另有 2 个数值单元格变化落在容限内，会单独计数。

常用选项：

| 参数 | 含义 |
| --- | --- |
| `--key 列名` | 主键列；多列主键就重复使用此参数 |
| `--numeric 列名` | 明确将这一列按数值比较；其他列按原始文字比较 |
| `--abs-tol 0.1` | 绝对容限，例如允许温度变化不超过 0.1 ℃ |
| `--rel-tol 0.01` | 相对容限，0.01 表示 1% |
| `--ignore 列名` | 忽略这一列的单元格变化，要求两份表都存在该列 |
| `--delimiter tab` | 制表符分隔；也可以指定 `;` 等单个字符 |
| `--encoding utf-16` | 明确指定编码；默认 UTF-8，兼容 BOM |
| `--format json` | 输出结构化 JSON；也支持 text、markdown |
| `--show-values` | 主动在报告中显示编号和单元格值 |
| `--max-details 20` | 最多显示 20 个变化事件，不影响完整计数和退出码 |

退出码：0 表示所选规则下相同；1 表示发现差异；2 表示输入或参数无效。

## 比较规则和边界

数值比较采用十进制计算，满足下面的条件才视为容限内：

```text
|旧值 − 新值| ≤ max(绝对容限, 相对容限 × max(|旧值|, |新值|))
```

作为 Python 库调用时，比较计算使用独立的十进制上下文，不受调用方的精度、指数范围
或异常设置影响，也不会修改调用方的设置和状态标志。

主键和普通文字列不会自动转成数字，因此“001”和“1”保持区别。
数值列中的空值、NaN、无穷大及格式错误会导致整次比较失败，包括新增或删除记录。
主键重复或为空也会停止比较，避免猜测配对。

新增或删除列属于表结构变化，始终计为差异。“未修改记录”只表示共有且参与比较的列
没有发生超出规则的变化，不能据此认定整张表的结构不变。

默认报告仍会显示列名、变化数量和 CSV 逻辑记录号；它不是匿名化工具。
记录号包括表头：表头为 1，第一条数据为 2，多行单元格仍算一条逻辑记录。
程序不联网、不上传、不修改输入文件、不执行单元格中的内容。

每份输入限制为 25 MiB、100,000 条记录、256 列，每个单元格最多 16,384 个字符。
这是面向中小型数据导出的内存工具，不适合超大表，不进行单位换算或统计显著性判断。
容限应按你的实验和比较目的确定。

项目提供 MIT 许可证、测试、跨平台 CI 和合成示例；详细语义以英文规则文档为准。
